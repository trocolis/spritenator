Spritenator {{VERSION}}

Spritenator is an indexed-color sprite editor, a cross-platform recreation of Character Maker 1999 by Yoji Ojima. It was designed for RPG Maker character sets and chip sets, but it works for any 16 or 256 color pixel art.

1. The basic workflow

The image (the canvas) is divided into cells the size of one character frame, 24×32 pixels by default (View > Character Size). You edit one cell at a time in the magnified drawing area:

  • Right-click a cell of the canvas to bring it into the drawing area.
  • Draw in the drawing area.
  • Left-click a cell of the canvas to write the drawing area into it.

With the canvas focused, the arrow keys move to the neighbouring cell and bring it into the drawing area. Transfer All (F3) brings the whole canvas into the drawing area. The drawing area is shared by all open images, so you can copy frames from one image to another.

2. The screen

  • Integrator (the tool panel) contains the palette, the color controls, the tools, the actual-size preview, the drawing area and the transformation buttons. Window > Reverse Canvas swaps it to the other side.
  • Canvas windows show each open image. A double frame follows the mouse and shows the cell that a click will read or write.
  • The status bar shows the position of the mouse in the canvas or in the drawing area.

In the palette, the left button selects the drawing color and the right button selects the background color. The R, G, B sliders edit the drawing color. Dragging a slider creates a single undo step.

3. Drawing tools and tones

Select a rectangle. A simple click removes the selection.
Zoom: the left button magnifies and the right button reduces.
Fill the adjacent area of the same color.
Thin (1 px) and thick (3 px) pens.
Straight line.
Rectangle, rounded rectangle and ellipse outlines.
The same shapes, filled.

All tools draw with the drawing color using the left button and with the background color using the right button. Press Esc to cancel the shape being drawn.

Tones (A to H) are screen patterns. Only the pixels covered by the pattern receive the color, which simulates intermediate shades. Tone A is solid. The button shifts the origin of the pattern.

4. Transformations

The buttons below the drawing area act on the selection, or on the whole drawing area when there is no selection:

  • shift up, right, down or left by one pixel (what leaves one side enters on the other);
  • flip vertically or horizontally;
  • symmetry: copy the top or left half mirrored onto the other half;
  • rotate 90 degrees, rotate by any angle, and stretch or shrink.

Also in the Edit menu:

  • Prepare Shadow turns every non-background pixel into the drawing color.
  • Text Input renders text without anti-aliasing.

5. Palette, mask and transparency

  • Transparent Color Effect (F8): when writing the drawing area into the canvas, pixels of the background color are skipped.
  • Mask: masked colors are protected, so pixels of those colors are never changed. In Mask Mode (F5):
    • left-clicking a palette color masks or unmasks it;
    • right-clicking inverts the mask;
    • double right-clicking clears it.
    Automask (F9) protects every color except the background color.
  • Gradation (Ctrl+D) interpolates the palette between the drawing and the background colors.
  • Edit Palette lets you:
    • exchange colors, keeping the look of the image;
    • remove unused colors;
    • reduce the colors to 15 bits, as RPG Maker 2000 does internally.
  • Load Palette reads .pal (RIFF or JASC), .act, or the palette of a BMP/PNG image. It can keep the pixel indices, move each color to the nearest new color, or reproduce the colors by dithering.

6. Animation preview

Open it with F2:

  1. Right-click a cell of the canvas to bring it into the drawing area.
  2. Press Add Cell to add that cell as a frame, or press Walk Cycle to add the RPG Maker walking sequence (frames 1-2-3-2) of that cell's direction.

The preview shows the current canvas, so your edits appear immediately.

7. Files and backups

Images are opened and saved as indexed PNG or BMP files. Files with 16 colors are written as 4-bit BMP files. You can also drag files onto the window to open them.

With a backup folder set (File > Set Backup Folder), the previous version of a file is copied there each time the file is overwritten.

The interface language can be chosen in View > Language. The change takes effect immediately.
