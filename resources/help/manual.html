Spritenator {{VERSION}}

Spritenator is a cross-platform sprite editor, loosely inspired by Character Maker 1999 by Yoji Ojima. It was designed for RPG Maker character sets and chip sets, but it works for any pixel art: true color with transparency (RGBA) or indexed with 2, 16 or 256 colors.

1. Editing and zoom

Each open image has its own tab, and you draw directly on the whole image. While the mouse is over the image, the pixels that the current tool would change are highlighted: one pixel for the thin pen, a "+" for the thick pen, the whole area for the fill tool. Pixels that the tone or the mask protect are not highlighted.

  • Mouse wheel: zoom in and out (from 12.5% to 3200%), keeping the pixel under the pointer in place.
  • Ctrl + wheel: scroll the image up and down; Ctrl + Shift + wheel: scroll it sideways. You can also drag the image with the middle button.
  • The zoom box in the status bar shows the zoom in percent; type a value or pick one from its list.
  • View menu: Zoom In, Zoom Out, Actual Size (100%) and Fit to Window. A newly opened image fits the window until you change its zoom.

Grids (View > Grids):

  • the main grid is 1×1 by default, so it outlines every pixel. You can make it larger (e.g. 2×2 or 8×8). It is hidden while its lines would be too close together on screen;
  • the sub grid has the size of one character frame (the “character size”, 24×32 by default) and also defines the animation frames.

Both grids can be shown or hidden in the View menu.

2. The screen

  • The side panel contains, from top to bottom: the tools (and the options of the current tool: the pen tip or the magic wand tolerance), the fill patterns (tones), the transformation buttons, the color controls and the palette (or the color wheel). Tools, tones and transformations stay in one row when the panel is wide and wrap to new rows as it gets narrower; drag the divider to resize the panel. Window > Reverse Canvas swaps it to the other side.
  • The tabs show each open image; drag a tab to reorder it and click its × to close it.
  • The status bar shows the position of the mouse in the image and the zoom of the active tab.

Two swatches show the primary color (left button) and the secondary color (right button). Click a swatch to make it the active one, which is the color the sliders edit.

  • Indexed images: in the palette, the left button selects the primary color and the right button the secondary color. The R, G, B sliders edit the palette entry of the active color; dragging a slider creates a single undo step.
  • RGBA images: the palette is replaced by a color wheel. The ring chooses the hue; the triangle inside it goes from the pure color to white and black. The left button sets the primary color and the right button the secondary one; the picked color also becomes the active one. The R, G, B and A (opacity) sliders edit the active color, and the wheel follows them.

3. Drawing tools and tones

Rectangular and oval selections (Shift: square or circle). A simple click removes the selection.
Point-to-point selection: click each corner. Close it with a double click, a click on the first point, the right button or Enter; Backspace removes the last point.
Freehand selection: draw the outline while holding the button.
Magic wand: selects the area of similar color. Below the tools, set the tolerance (0% = only the same color) and Contiguous (only the area connected to the clicked pixel).
Fill the adjacent area of the same color.
Pen. Below the tools, choose the tip ( square or round) and the size, from 1 to 64 pixels; [ and ] change the size. With even sizes, the pointer is on the upper-left pixel of the center.
Straight line.
Rectangle, rounded rectangle and ellipse outlines.
The same shapes, filled.
The line and the shapes draw their outline with the same tip as the pen (shape and size, below the tools): with a large tip the outline gets thicker, centered on the shape.

All tools draw with the drawing color using the left button and with the background color using the right button. Press Esc to cancel the shape being drawn.

Tones (A to H) are screen patterns. Only the pixels covered by the pattern receive the color, which simulates intermediate shades. Tone A is solid. The button shifts the origin of the pattern.

Working with selections

  • When starting a selection, Shift adds to the current one and Ctrl subtracts from it.
  • While there is a selection, drawing tools only paint inside it.
  • Esc cancels what is in progress (a point-to-point outline, a transformation); with nothing in progress, it removes the selection.
  • With a selection tool active, a box with 8 handles surrounds the selection, as in modern image editors:
    • drag inside the selection to move the pixels;
    • drag a handle to scale (Shift on a corner keeps the proportion);
    • drag just outside a corner to rotate (Shift: steps of 15°).
    The pixels float until you press Enter, click outside the selection or change to another tool; the whole transformation is then a single undo step. Esc or Undo cancels it.
  • Keyboard (all shortcuts can be changed in Edit > Keyboard Shortcuts): the arrows move the selected pixels (Shift: 8 pixels; Ctrl: only the outline); R / Shift+R rotate 90° right / left; E / Shift+E flip horizontally / vertically; Del clears; Ctrl+A, Ctrl+Shift+A and Ctrl+I select all, deselect and invert the selection.

4. Transformations

The transformation buttons of the side panel act on the selection, or on the whole image when there is no selection. With a selection, rotating and flipping take the shape of the selection along; shifting and symmetry change only the selected pixels:

  • shift up, right, down or left by one pixel (what leaves one side enters on the other);
  • flip vertically or horizontally;
  • symmetry: copy the top or left half mirrored onto the other half;
  • rotate 90 degrees, rotate by any angle, and stretch or shrink.

Also in the Edit menu:

  • Prepare Shadow turns every non-background pixel into the drawing color.
  • Text Input renders text without anti-aliasing.

5. Palette, mask and transparency

  • Transparent Color Effect (F8): when pasting, pixels of the background color are skipped, so they do not cover the image.
  • Edit Palette is opened with Shift+P (Shift+E flips the selection).
  • Mask: masked colors are protected, so pixels of those colors are never changed. In Mask Mode (F5):
    • left-clicking a palette color masks or unmasks it;
    • right-clicking inverts the mask;
    • double right-clicking clears it.
    Automask (F9) protects every color except the background color.
  • Gradation (Ctrl+D) interpolates the palette between the drawing and the background colors.
  • Edit Palette lets you:
    • exchange colors, keeping the look of the image;
    • remove unused colors;
    • reduce the colors to 15 bits, as RPG Maker 2000 does internally.
  • Load Palette reads .pal (RIFF or JASC), .act, or the palette of a BMP/PNG image. It can keep the pixel indices, move each color to the nearest new color, or reproduce the colors by dithering.

6. Animation preview

Open it with F2:

  1. Click the image inside a cell of the sub grid (any tool will do; the selection tool does not change pixels).
  2. Press Add Cell to add that cell as a frame, or press Walk Cycle to add the RPG Maker walking sequence (frames 1-2-3-2) of that cell's direction.

The preview shows the current image, so your edits appear immediately.

7. Files and backups

New images. In File > New, choose the size and the colors: RGBA (true color with transparency) or Indexed, with 256, 16 or 2 colors (and, optionally, a copy of the palette of the active image). There are no presets: the Used before list keeps the last 8 combinations of size and colors that you created, most recent first, and the dialog opens with the latest one.

Color modes. RGBA images:

  • show a checkerboard behind transparent pixels;
  • are drawn with the primary color (left button) and the secondary color (right button, transparent by default, so it erases);
  • have no palette, so the palette commands and the mask are disabled;
  • with Transparent Color Effect, skip fully transparent pixels when pasting;
  • can only be saved as PNG, because BMP files cannot store transparency.

Copying from an image and pasting into an image of the other mode converts the pasted pixels.

Indexed images are opened and saved as PNG or BMP files; files in true color open as RGBA. BMP files are written with 1, 4 or 8 bits per pixel, according to the number of colors. You can also drag files onto the window to open them.

With a backup folder set (File > Set Backup Folder), the previous version of a file is copied there each time the file is overwritten.

The interface language can be chosen in View > Language, and the window theme (the system one, light or dark) in View > Theme. Both changes take effect immediately.
